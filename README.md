## 🧠 Overview

This is my **personal portfolio website** built with pure HTML, CSS, and JavaScript — no frameworks, no build tools. It features a sleek dark-themed design with animated background blobs, glassmorphism cards, smooth scroll animations, and a fully responsive layout that works beautifully on all screen sizes.

The portfolio highlights my journey as a **Computer Science (AI & ML)** student at Nagarjuna College of Engineering and Technology, Bengaluru, with an **8.93 CGPA**. It showcases my expertise in Python, Java, Machine Learning, NLP, IoT, and full-stack development.

## 🚀 Getting Started

### Option 1: Just Open It
Simply double-click `index.html` — it works directly in your browser with no server needed!

### Option 2: Clone & Run
```bash
git clone https://github.com/swethasweth19/portfolio.git
cd portfolio
```
Then open `index.html` in your browser, or use a live server:
```bash
# Using VS Code Live Server extension, or:
npx serve .
```

## 🎨 Customisation

Want to make this portfolio your own? Here's what to edit:

| What to Change | Where |
|----------------|-------|
| **Name, title, bio** | `index.html` — Hero and About sections |
| **Projects** | `index.html` — Projects section (add/remove cards) |
| **Skills & percentages** | `index.html` — Skills section (update progress bar widths) |
| **Colours & theme** | `style.css` — CSS custom properties at the top |
| **Profile photo** | Save your image as `assets/profile.jpg` |
| **Social links** | `index.html` — Update GitHub, LinkedIn, and email URLs |
| **Animations** | `script.js` — Modify scroll thresholds and timing |

## 🌐 Deployment

### GitHub Pages (Free & Easy)
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **main** branch, root folder
4. Your site will be live at `https://swethasweth19.github.io/portfolio/`

### Other Options
- **Netlify** — Drag & drop the folder
- **Vercel** — Import the GitHub repo
- **Cloudflare Pages** — Connect your repo
